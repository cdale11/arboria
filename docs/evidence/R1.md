  `run.sh`, launcher check mode, repeat/stale-build/path tests.

  bounded command envelopes, receipts, and stream snapshots/resync.

  pause/resume/speed, manual checkpoints, named saves, restore, autosave, and
  paused lifecycle controls.
- Persistence and recovery: SQLite metadata, immutable checkpoint generations,
  startup cleanup, active-checkpoint validation, parent-chain fallback,
  migration for nursery schemas 1-4, atomic-save failure injection, protected
  plant persistence, and current-domain export/import archives.
- Biology and species: organ topology, bounded vegetative growth, bounded
  light-driven carbon assimilation, finite root-zone water and reservoir,
  finite substrate N/P/K uptake, deficiency stress, damage/death, six provisional
  species, and documented species coverage boundaries.
- Nursery, UI, and economy: authenticated plant projections/inspection,
  generated display-only SVG nursery view, desktop and touch-sized controls,
  watering, shop purchases, demand-limited sales, plant sale protection,
  checkpoints/named saves/restore/export/import controls, and finite cash/water
  accounting.

## Performance Characterization

Command:

```bash
python -m pytest tests/performance -m performance
```

The performance suite passed 7 tests in 221.05 seconds on the inspected host.
It builds heterogeneous starter nurseries through the public pure biology
kernels and checks finite state and root-zone capacity bounds. The ten-sim-year
soak uses 50 plants because a full 500-plant decade is not yet tractable in the
current pure-Python kernel; it ran 1,051,200 ticks in 150.3 seconds and ended
finite and within capacity, with 50 dead plants after finite unwatered nutrient
and water supplies were exhausted.

Measured single-tick samples from the same host:

| Population | Samples | p50 | p95 | p99 | Result |
| --- | ---: | ---: | ---: | ---: | --- |
| 500 plants / 1,500 organs | 30 | 96.6 ms | 98.9 ms | 101.0 ms | R1 provisional latency target passes |
| 1,000 plants / 3,000 organs | 15 | 327.4 ms | 338.3 ms | 338.3 ms | R6 provisional latency target not met |

The optimization removed redundant whole-world topology validation from three
private per-plant exchange helpers and changed those updates to indexed
in-place replacement while retaining validation at the public
`advance_nursery` boundaries. The observed 500-plant single tick improved from
approximately 2.06 seconds to 0.097 seconds. Remaining 1,000-plant cost is
dominated by full-organ-list work in growth and per-plant assimilation; no
offscreen or biological activity was disabled.

The reproducible harness lives in `tests/performance/harness.py` and
`tests/performance/test_performance.py`; no generated timing artifact is
committed.

The requested full-target command was attempted with 500 plants and 10 simulated
years using the same `run_soak` path. The nursery built in 0.71 seconds, but the
1,051,200-tick soak exceeded a 900-second execution budget and was terminated
without a final checkpoint. This is evidence of an unresolved scale limitation,
not a passing decade-stability result.

## Release Blockers Still Open

- `[AI/ML]` companion authority, neural learning, learner persistence,
  optimizer/replay/RNG continuation, and learning holdout/ablation evidence are
  not implemented.
- Current-domain export/import does not include learner state because no learner
  exists yet.
- The R1 500-plant latency target is characterized and passes on this host, but
  the complete aggregate performance gate remains open: no 24-real-hour soak
  has been run and the full 500-plant ten-sim-year soak is not yet tractable.
- No physical touch-device smoke test has been recorded; browser e2e uses the
  locked Vitest/jsdom stack.
- The full target-host 500-plant soak, 24-real-hour soak, and complete
  performance gate have not been run.
- Fertilizer items, price forecasting, species calibration, companion behavior,
  and later horticultural mechanics remain deferred.

R1 therefore has a substantial playable foundation, but the roadmap must not be
marked as a complete R1 release until the open AI/ML, physical-device, and
performance/soak gates are satisfied or explicitly rescoped.
